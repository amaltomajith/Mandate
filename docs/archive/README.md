# Archive

These documents describe Mandate as it was built for the Razorpay AI Buildathon: a policy gate for
payments proposed by *external* agents, with a simulation, counter-offers (MRTR) and campaigns.
Those features were removed when the project became an autonomous store manager. The payment
gate itself survived and is described in `../ARCHITECTURE.md`.

Kept for history and for the reasoning in them (the MCP v1 vs v2 analysis, the earlier tenancy
audit), not as a description of the current system.
