# Mandate

A merchant-owned control plane for agent-initiated money actions. Built for
Razorpay's hackathon, Track 01 (AI Growth & Agentic Commerce).

**Start with [HANDOVER.md](./HANDOVER.md)** — build status, architecture,
setup steps, and the demo script all live there. This file is intentionally
short.

```bash
npm install
npm run dev
```

Requires a Supabase project, Razorpay test-mode keys, and a Gemini API key —
see HANDOVER.md §8 before running anything beyond `npm run build`.
